用語集

解説テーマ：用語・システム
世界設定の項目には、物語の結末に関わる内容を含む。

物語の用語とシステムの用語をまとめて、五十音順に並べている。くわしくは各項目のリンク先を参照。

用語分類意味くわしく
AP（アビリティポイント） システム バトルに勝つと得られるポイント。装備品に付いたアビリティを修得するのに使う。倒したモンスターの数ではなく、勝った敵パーティーごとに決まっている →
ATE（アクティブタイムイベント） システム パーティーが別行動しているときなどに、操作していないキャラクターの様子を見られるイベント。SELECTボタンで開始できる。見るかどうかでアイテムの入手や会話が変わるものがある →
ふたつの月 世界設定 ガイアの空に浮かぶ青い月と赤い月。青はもともとガイアにあった月、赤はテラの月で、融合のときに取り残された。16日ごとに重なって前面の色が入れかわる →
アクティブタイムバトル（ATB） システム FF9のバトルの仕組み。各キャラクターのATBゲージが満タンになるとコマンドを入力できる。ゲージの増加速度は素早さやヘイスト・スロウで変わる →
イーファの樹 世界設定 ガーランドがガイアに移植したテラの魔法樹。地表に出ている部分は根で、幹は星の内部に伸びている。魂の循環を制御し、根元にはソウルディバイダーが据えられている →
ガイア 世界設定 FF9の舞台となる星。青い輝きのクリスタルを持つ若い星で、魔法より機械が中心になりつつある文明を持つ →
クアッドミスト システム FF9のカードゲーム。街の人に話しかけて対戦し、勝つと相手のカードを奪える。全100種類 →
クリスタル 世界設定 星の中心にあって魂の循環をつかさどる存在。生物の記憶を蓄積して成長し、老いると星とともに宇宙に還る。ガイアは青、テラは赤の輝き →
ジェノム 世界設定 融合が終わって復活するテラの民の魂を宿す器として創り出された生命体。テラの因子をもとにしている。ジタンとクジャもジェノムで、ジタンはトランス能力を備える →
ソウルディバイダー 世界設定 イーファの樹の根元に据えられた装置。イーファがはじいた魂からテラの因子だけを精製して取り出す →
テラ 世界設定 高度に発達した魔法文明の世界。赤い輝きのクリスタルを持つ。融合の失敗のあとガイアの内部に移り、テラの民は眠りについている →
トランス システム 敵の攻撃を受けてトランスゲージが満タンになると起こる強化状態。特定のコマンドが専用コマンドに変わり、特定の攻撃のダメージが増える。コマンドを実行するたびにゲージが減る →
召喚獣 世界設定 クリスタルから生まれ、クリスタルを守る高エネルギー体。クリスタルに蓄積された記憶が具現化した存在で、召喚士の一族が交感できる →
合成 システム 合成屋で素材のアイテム2つと手数料を渡して、新しいアイテムを作ってもらうこと。ショップで買えない装備品やアクセサリの大半は合成で手に入る →
融合 世界設定 テラの民が用いる究極の魔法の技。老いたクリスタルの星の民が、幼い星の無垢なクリスタルを取りこんで魂の循環を奪う。ガイアへの融合は失敗し、大変動を引き起こした →
輝く島 世界設定 エスト・ガザの近海にある、光を放つ島。ガイアとテラをつなぐ次元の狭間からクリスタルの輝きがもれたもので、テラへの出入り口になる。エスト・ガザの住人の信仰の対象 →
霧 世界設定 霧の大陸を覆う霧。イーファの根を通じて送りこまれた魂が形を変えたもので、人々を高地へ追いやり、争いを頻発させた。飛空艇の霧機関の動力にもなっている。黒魔道士や霧の魔獣は霧をもとに生み出された →
魂の循環 世界設定 クリスタルが魂を送り出して生物が生まれ、死ぬと記憶をともなった魂がクリスタルに還る流れ。ガイアとテラの融合が中途半端に終わったため、ガイアにはふたつの循環が存在する →
魔石力 システム サポートアビリティを装備するときに消費する能力値。高いほど一度にたくさんのサポートアビリティを装備できる →
黒魔道士 世界設定 霧をもとに生み出された、ジェノムと対をなす存在。ガイアの因子をもとにしている。本来は感情の抑制された存在だが、戦争の中で個体差が生じた →
