アレクサンドリア（ガーネット即位時）

ストーリー攻略 20 DISC 3 前：マダイン・サリ（2回目）・イーファの樹（クジャ追跡時） 次：トレノ（カードゲーム大会）

ガーネットが女王となる日まで、残すところあと3日。新女王の誕生にアレクサンドリアの街は沸き立ち、祝いの準備に余念がない。一方ジタンは、彼女が手の届かないところへ行ってしまうことに、やるせない思いを抱いていた。

マップアレクサンドリア（ガーネット即位時）、アレクサンドリア城（ラブレター時〜ガーネット即位時）
メンバージタン → ビビ → エーコ → ジタン・ビビ → ジタン・ビビ・フライヤ・サラマンダー
入手できるだいじなもの天竜の爪、砂漠の星、星宮レオ

攻略手順

  1. 酒場の外でブランクと再会　ATE「なんて、おっきな……」「くじらのように！」「風が舞い上がる為には」「アルテミシオン」が発生する。
  2. 小劇場に入る　裏通りでブランクの頼みを引き受けると入れる。入ると操作がビビに変わり、以後アレクサンドリアを探索できなくなる。発生中のATEも消え、ミニゲーム「かけっこ」もできなくなるので、やり残しがないか確かめてから。
  3. ジタンへラブレターを届けに行く　エーコの操作。城でのダガーとの会話が終わるとオパール・トパーズ・アメジストが自動的に手に入る。行ける範囲は限られ、迷うことはない。警護室のセーブモーグリのモッシュでセーブできる。
  4. ダガーに会いに行く　ジタンとビビの操作。大通り②からワールドマップへ出られ、小劇場でシャッフルゲームもできる。船着場へ行くとフライヤとサラマンダーが加わり、以後は渡し舟で街と城を行き来できる。
  5. 城でダガーに会う　天竜の爪と砂漠の星を入手。ダガーと会うと城も街も探索できなくなる。城の船着場（外観②）や左塔①には、この時期にしか取れないアイテムがあるので、先に探索をすませる。
  6. トットの案内でトレノへ向かう　強制ATE「月なきみそらの道化師たち」。

宝箱・入手アイテム

場所中身
城下町2680ギル、3927ギル、フェニックスの羽、万能薬、エーテル、目薬、ポーション、テント、3ギル、アイロネート・ゴブリン・ファング・シヴァ・ラムウのカード（タンタラス上演時に取ったものは無い）
城 資料室本
城 外観・左塔ラピスラズリ、エーテル、フェニックスの羽（ガーネット即位時のみ）
城 昇降室①星宮レオ（崩壊後にも入手できる）

その他のイベント・ミニゲーム

続・カバオのカード探し

DISC1 と同じ要領で尖塔を探すと、カバオのシヴァのカードとラムウのカードが手に入る。DISC1 で取っていなければアイロネート・ゴブリン・ファングのカードも同時に手に入る。カバオのカードを手に入れる機会はこれが最後。

スティルツキン登場

ビビの操作で尖塔を訪れると、セーブモーグリのクポの隣にスティルツキンがいる。フェニックスの羽・ハイポーション・エリクサーの3点セットを777ギルで買える。ATE「アルテミシオン」を見るとアルテミシオンも現れる。操作がジタンに戻ると姿を消す。

かけっこ・シャッフルゲーム

ジタンの操作中はかけっこ、ビビと合流してからはシャッフルゲームで遊べる。

取り返しのつかない要素

  • 小劇場に入ると街を探索できなくなり、発生中のATEも消える。
  • ダガーと会うと城も街も探索できなくなる。船着場と左塔①のアイテムはその前に。
  • カバオのカードを手に入れられるのはこれが最後。
