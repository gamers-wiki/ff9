プライバシーポリシー

制定：2026/09/06 最終更新：2026/09/06

当サイト「ファイナルファンタジーIX 攻略Wiki」（https://gamers-wiki.github.io/ff9/）における訪問者の情報の取り扱い、 お問い合わせフォームとアフィリエイトリンクの取り扱いについて定めます。

運営について

当サイトは、ゲーム「ファイナルファンタジーIX」の攻略情報をまとめた非公式のファンサイトで、個人が運営しています。 株式会社スクウェア・エニックスをはじめとする権利者、および後述する各サービスの提供事業者とは、一切の資本関係・提携関係がありません。

取得する情報について

当サイトには、会員登録、コメント投稿、読者による編集などの機能がありません。 Googleアナリティクスなど、外部のアクセス解析サービスも使用していません。

ただし、どのページがよく読まれているかを知るため、運営者が用意した仕組みで 閲覧の記録を取得しています。取得するのは次の情報です。

  • 閲覧したページのURLとタイトル
  • 参照元のURL（他のサイトのリンクをたどって来た場合）
  • 端末の種別（パソコン・スマートフォン・タブレットの別）
  • 同じ人の続けての閲覧かどうかを見分けるための、ブラウザに保存した一時的な符号
  • IPアドレスとブラウザの種類から計算した文字列。元に戻せない形に変換したもので、IPアドレスそのものは保存しません

氏名やメールアドレスなど、個人を直接特定できる情報は取得しません。 取得した記録は運営者だけが見るもので、第三者へ提供することはありません。

当サイトは GitHub, Inc. が提供する GitHub Pages で公開しています。 ページの配信にあたり、GitHub がアクセスログ（IPアドレスなど）を記録することがあります。 その取り扱いは GitHub のプライバシーに関する声明に従います。

サイト内検索について

サイト内検索は、あらかじめ用意した索引データをブラウザに読み込み、ブラウザの中だけで検索する仕組みです。 入力された語句がサーバーに送られたり、保存されたりすることはありません。

Cookie（クッキー）について

当サイト自身は Cookie を発行しません。ただし、後述する Amazon のリンクを経由した場合は、Amazon が Cookie を発行することがあります。 Cookie はブラウザの設定でいつでも無効にしたり削除したりできます。当サイトのページを読むうえで Cookie は必要ないため、無効にしても閲覧に支障はありません。

なお、上に書いた閲覧の記録では、同じ人の続けての閲覧かどうかを見分けるために、 ブラウザの保存領域（ローカルストレージ）へ一時的な符号を保存します。Cookie ではありませんが、 同じくブラウザの設定でサイトのデータを削除すれば、いつでも消せます。

お問い合わせフォームについて

お問い合わせには、Google LLC が提供する「Googleフォーム」を利用しています。 フォームに入力された内容（お名前・メールアドレス・お問い合わせの種類・該当ページのURL・お問い合わせ内容）は Google のサーバーに送信・保存され、 当サイトの運営者がそれを閲覧します。取得した内容は、お返事とサイトの修正のためだけに使い、第三者に提供することはありません。

Google によるデータの取り扱いは、Google のプライバシーポリシーに従います。 フォームには、お問い合わせに必要な範囲を超える個人情報を入力しないでください。
